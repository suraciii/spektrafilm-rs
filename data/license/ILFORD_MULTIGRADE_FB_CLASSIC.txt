The plotted curve is a representative manufacturer drawing, not a measurement
of a particular box. The plotted D-min proxy is treated as 0.0; the D-max
endpoint (about 2.0814) is a graph endpoint, not a measured Dmax. The x-axis is
not calibrated to absolute lux-seconds: the filter-2 curve reaches density 0.6
at source x about 0.735 while ISO P230 implies log10(1000/230)=0.638. ISO P230
is retained as metadata, not used as the profile exposure origin.

Page 1 of the technical sheet has only a "Relative Sensitivity" ordinate with
no numeric scale and is not grade-specific. The profile therefore uses a flat
0.0 log-sensitivity placeholder. It is not a measured spectral sensitivity and
does not predict coloured light or variable-contrast filtration.

No measured base spectrum, fluorescence, surface BRDF, batch variation,
densitometer, scanner target or matched physical print is available. This is a
fixed filter-2/grade-2 source-curve approximation, not a complete MULTIGRADE
model.
