SPEKTRAFILM / GRAIN V3 / 研究与交互示意

让乳剂里的颗粒形成图像

光改变已有晶体的显影概率；显影产物改变局部吸收；印相或扫描把透过胶片的光积分为像素。颗粒的形态与图像内容由同一过程产生。

适用范围：下面以常规彩色负片为主。乳剂中的卤化银晶体、显影银、最终染料云、屏幕上看到的颗粒纹理是不同对象。黑白银盐负片主要保留金属银；彩色负片经漂白定影主要留下染料。反转片还有不同的显影流程。

01 · 同一片乳剂，改变曝光

拖动曝光：晶体位置、大小和各自的随机阈值保持不变，更多或更少的晶体被激活。改变扫描孔径：乳剂和显影结果保持不变，变化的是每个输出像素收集的光。

① 曝光分布 H(x,y)

投到乳剂上的光

左暗右亮，包含形状和细线。这里用单个感色组解释成像；真实相机输入应按波长与感色灵敏度积分。

② 固定晶体 + 曝光依赖的激活

快、中、慢三个子层

灰色是未激活晶体；青 / 橙 / 紫是快 / 中 / 慢子层的已激活晶体投影。颜色仅用于区分子层，不是染料颜色。

③ 显影产物的空间分布 → 透射率

染料云重叠构成负像

高曝光区域通常有更多染料，透光更少。局部团块来自云的尺寸、重叠和深度投影；不需要让晶体迁移聚团。

④ 先透射，再按孔径积分

扫描后观察

孔径越大，纹理和细节越容易被平均。为便于辨认形状，此处仅显示 1 − 平均透射率；不是完整彩负反演或印相。

这是教学模型，不是 V3 原型或实测胶片。160 × 60 µm 的示意区域，三组固定随机晶体，简化响应 p = 1 − exp(−sH)，以高斯核表示染料云，采用方形扫描孔径。快层的粒径更大、灵敏度更高是演示设定；具体胶片需实测标定。未模拟显影化学、真实多层光谱、镜头 PSF、散射或扫描电子噪声。

02 · 真实过程里，“颗粒聚集”发生在哪里？

涂布乳剂晶体已有位置、形状、大小和深度曝光 / 潜影吸收光子，形成能催化显影的潜影中心显影 / 漂定局部反应生成染料；彩负去除银和未显影卤化银光学读取吸收、空间积分和采样共同决定可见纹理

单个晶体的响应具有阈值和统计性，不能简单等同于“一个光子变成一个颗粒”。彩色负片常有不同速度的感色子层；实际层数、粒径与灵敏度分布依胶片而异。Kodak 对 VISION3 500T 的资料还明确描述了降低阴影颗粒的染料分层技术。

屏幕上的一个粗团块，可能汇集多个染料云、多个深度以及扫描系统的低通响应。显影抑制、层间作用会改变邻域响应；它们不能一概替换成独立低频噪声场。粒径也不是图像细节的硬截止：应看整条链路的 MTF 与信噪比。

03 · 亮度如何改变颗粒？

低曝光

少数敏感晶体先被激活。负片密度低；最终照片暗部的颗粒还取决于反演、印相对比度与扫描噪声。

中间曝光

更多晶体和子层参与。覆盖率、随机波动与云重叠一起变化；多个速度子层的响应会交叠。

高曝光

各子层逐渐饱和，云覆盖更加连续。密度波动与输出亮度波动不等价；不能用一个固定高光权重概括所有胶片。

必须区分三个坐标：场景曝光 H、负片密度 D、最终图像亮度 Y。负片的高密度通常来自高曝光，但扫描底片本身的透射亮度反而低。Dehancer 的 Shadows / Midtones / Highlights 是输入 RGB 的亮度分区，不能直接当作乳剂的三种速度子层。

04 · 三种已有实现，究竟在做什么？

对象图像与颗粒的关系已核实的边界
SpektraFilm V1总密度反查 3 × 3 子层；按每像素粒子数抽样随机密度，经染料云模糊、子层求和，再进入印相 / 扫描。有 µm 尺度与密度域耦合；没有固定晶体位置 / 形状 / 深度。候选粒子统计随目标密度改变，按输出栅格重新抽样。
Dehancer 已分析 OFX程序纹理受局部亮度影响，九点纹理重采样；用亮度分区 Overlay 混合。Film Resolution 先降低图像分辨能力。厂商“图像由颗粒组成”的视觉目标不等于逐晶体曝光模拟。已分析 kernel 明确读取现有 RGB 并混合生成纹理；不把一个版本的证据推广到所有产品。
当前 Grain V2扫描 RGB 按所选输出空间编码后进入 Grain；内核不转换曲线或 primaries。程序颗粒、分区混合与分辨率处理后，仅在线性导出时解码。恢复内容相位、sine permutation、half 存储和宿主滤波语义；独立三角函数允许与厂商设备产生不同的随机纹理。不代表感光乳剂成像。

代码依据：grain.rs · layer_particle_model / apply_grain_to_density_layers；filming.rs · 子层密度插值；scanning.rs · V2 接入；Dehancer 逆向笔记 §§5–6、11。

展开：V1 为什么已经有亮度相关的随机性，却仍不是固定乳剂？
p = clamp(D_target / D_max) s = 1 − p · uniformity · (1 − ε) M ~ Poisson(N / s) K | M ~ Binomial(M, p) D_sample = K · (D_max / N) · s E[D_sample] = D_max · p Var[D_sample] = (D_max² / N) · p · s

以上是未滤波、精确分布分支、单子层、给定 p 的矩；fast_stats 是近似采样。N 由像素面积 / 有效粒子面积等决定。在 uniformity 接近 1 时，p·s 近似 p(1−p)，所以密度方差通常在中间响应较大。子层求和、密度偏置、滤波、微结构场与非线性扫描会进一步改变它。

M 的均值 N/s 随 p 改变：这是用于拟合密度统计的模型，不是曝光前固定的一批晶体。相同随机 seed 可以重现同一调用，但不保证换分辨率、裁切或曝光后仍对应同一片物理乳剂。

05 · V3 建议：以等效成像为目标，扩展 V1

目标是物理响应与最终结果等效，不要求内部过程逐步相同。优先采用曝光条件下的分层随机密度场，保留 V1 的感色曲线、特性曲线、片基 / 染料光谱和印相 / 扫描链。是否显式生成晶体，取决于它是否比统计模型更有效地改善可观察结果；固定晶体不是验收条件。

每个感色子层的曝光 / 平均密度 → 条件统计：密度分布、空间相关、跨通道相关、有效物理尺度 → 空间相关的随机密度场（允许解析近似、滤波或稀疏云核） → 等效透射与孔径积分 → 现有印相 / 扫描链 物理约束：正确的平均吸收、曝光响应、尺度变化与细节传递 结果约束：颗粒形态 / 色彩 / 亮度分布与真实样本在目标范围内相符

第一步选定一种负片和一组受控曝光，测量或确定目标统计，再检查 V1 缺失哪些项。只有独立逐像素采样和固定模糊核无法匹配时，才增加曝光相关空间核、非高斯密度分布或通道相关等必要能力。保留现有 DIR 的宏观作用，避免重复计算同一种效应。V1 未保存晶体、候选数随密度改变，本身都不是“不等效”的证据。

候选 A · 分层统计密度场（优先）

直接匹配不同曝光下的响应和纹理统计，让随机密度参与吸收、印相与扫描。可以作为正式渲染模型；只要物理约束、观感和跨尺度结果通过验收，就无需再还原微观过程。

候选 B · 空间粒子 / 染料云（可选参考）

用于解释云重叠、检查近似或弥补统计模型难以表达的形态。仅在实测收益足够时引入。教学示意中的固定晶体帮助理解因果，不限定 V3 的实现架构。

等效近似必须保留非线性读取的结果。一个采样孔径，一半 D=0、一半 D=2，平均透射率是 0.505；先平均密度得到 D=1，透射率只有 0.1。可以直接计算透射光积分，也可以用经验证的统计积分 / 等效算子替代。只保留平均密度通常不够；匹配单个 RMS 或功率谱也不足以证明所有图像结果等效。

06 · 用哪些可观察结果检验“等效”？

  1. 平均响应：多次乳剂实现 / 足够面积平均后的 D–log H 曲线和扫描颜色，匹配目标胶片；不能只比较颗粒开关前的像素均值。
  2. 亮度与色彩统计：按曝光测量颗粒 RMS、空间功率谱 / 自相关和跨感色通道协方差。Kodak RMS 数据须对应它规定的测量孔径；单个 RMS 数值不能决定纹理形态。
  3. 形态与细节：真实高分辨扫描约束颗粒形状、团块、稀疏尾部与彩色斑点；边缘和细线检验 MTF 及边缘附近的随机响应，均匀天空检查方向性伪影。无需取得每颗晶体的真实参数。
  4. 尺度一致性：相同画幅、不同输出尺寸和裁切下，颗粒物理尺度和读取后的统计应一致。对同一随机场比较直接低分辨读取与高分辨后按同孔径读取；不要求场的内部表示是晶体。
  5. 计算一致性：CPU / GPU 结果误差有界，重复渲染稳定，拼块无接缝；以暗部、天空、皮肤、强边缘与多种输出尺度检查实际观感。逐像素匹配某张真实胶片的随机纹理不是要求。

Newson 等的连续 Boolean 模型可用于建立参考，基于其统计的等效算法也可直接用于生产渲染。现有 profile 不足以唯一确定微观乳剂，但 V3 无需解决这个反问题：只拟合影响目标成像范围的有效参数。最终选择应由效果、误差和运行成本决定；未经样本验证，不能宣称已经达到等效。
